### Inside the Package:
1.  **Study Guide:** Every chapter is a detective "case" with explanations, hands-on activities, optional simulator Labs, and self-check questions.
2.  **Separate Test Bank:** True/False, Multiple Choice, and Open-ended questions covering all 16 chapters.
3.  **Answer Key:** Answers with explanations for every question.
4.  **Supporting Activity Files:** Our offline HTML simulators, also available in [`Simulators_SG/`](../../Simulators_SG).

## 🗂️ Study Guide Structure
| Section | Chapters | Focus |
| :--- | :-: | :--- |
| 🖥️ **I. Inside the Machine** | 1–4 | How a single device works and what slows it down |
| 🌐 **II. How Devices Talk** | 5–8 | Networks, the cloud, and the edge |
| 🤖 **III. How AI Learns** | 9–12 | Behaviourist AI: learning from rewards and trial and error |
| 🛠️ **IV. Putting It Together** | 13–16 | Real-world limits, safety and ethics, and mini-projects |

## 🧭 How to Use This Study Guide
1.  **Read** the cases in order (Chapters 1 → 16), because each one builds on the previous.
2.  **Try** each activity, then the matching simulator from [`Simulators_SG/`](../../Simulators_SG) to test your prediction.
3.  **Test** yourself with the Test Bank *before* opening the Answer Key.
4.  **Review** with the [Final Video Tutorials](../Task%204:%20Final%20Video%20Tutorials/README.md) and [Final PPT Slides](../Task%203:%20Final%20PPT%20Slides/README.md), which follow the same cases.
