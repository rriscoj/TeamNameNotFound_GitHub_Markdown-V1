# 📖 Module Chapters

Welcome to the core curriculum folder! This directory houses the actual educational content for our **Hardware, Networks & Behaviorist AI** module. 

To make the learning experience digestible for beginners, we have organized the markdown content into four distinct, logically sequenced sections.

## 🎯 Intended Learning Outcomes
By completing this module, learners will develop both foundational knowledge and practical problem-solving skills. Specifically, learners will be able to:
*   **Understand** the fundamental concepts of computer hardware, data networks, and how artificial intelligence learns through trial and error (behaviourist AI).
*   **Explain** in simple terms how hardware components (like processors, memory, and sensors) and network connections affect how fast smart devices and AI applications can run.
*   **Grasp** the basic ideas behind reinforcement learning, including how an AI agent interacts with its environment using actions, states, and rewards.
*   **Explore** through hands-on activities how real-world gadgets (like delivery robots, smart home devices, and self-driving vehicles) make decisions while dealing with battery, memory, network latency, and speed limits.

## 🧠 Target Audience & Prerequisites
**Required Learning Level:** Beginner / High School Level
*   **What you need:** Everyday experience using computers or smartphones, basic middle-school arithmetic skills (understanding simple scores, percentages, and cause-and-effect rules), and a general curiosity about how technology works. 
*   **What you DON'T need:** No prior coding, advanced math, or electronics experience is required to succeed in this module.

## 🗂️ Curriculum Breakdown

### 🖥️ I. Hardware Foundations: Inside the Machine
This section demystifies the physical components that make computing and AI possible.
*   **Chapter 1:** What is a Computer? (Hardware basics, processors, memory, and the instruction loop)
*   **Chapter 2:** Super-Powered Chips (GPUs vs. TPUs)
*   **Chapter 3:** Smart & Efficient Tech (Low-power microchips for wearables and smart devices)
*   **Chapter 4:** Sensors and Perception (How computers gather data using cameras, LiDAR, etc.)

### 🌐 II. Network Infrastructure: How Devices Talk
This section explains how data travels between devices and servers to support AI applications.
*   **Chapter 5:** The Highway of Data (Wi-Fi, internet cables, and high-speed connections)
*   **Chapter 6:** Working Together (How cloud servers share large AI training tasks)
*   **Chapter 7:** Keeping Traffic Flowing (Understanding lag, latency, and bandwidth)
*   **Chapter 8:** Edge vs. Cloud AI (Processing on-device vs. across the internet)

### 🤖 III. Behaviourist AI and Trial-and-Error: How AI Learns
This section introduces reinforcement learning and how AI systems make decisions based on feedback.
*   **Chapter 9:** The Roots of Smart Behavior (Animal training concepts applied to computer science)
*   **Chapter 10:** Rules of the Game (States, actions, and rewards)
*   **Chapter 11:** Learning by Doing (Exploration vs. exploitation in AI)
*   **Chapter 12:** Multi-Agent Systems (How multiple AIs cooperate or compete)

### 🛠️ IV. Co-Design and Simple Projects: Putting it Together
This final section combines hardware limits, network delays, and AI behavior into real-world applications and hands-on projects.
*   **Chapter 13:** AI in the Real World (How heat, hardware, and network delays affect robots)
*   **Chapter 14:** Safety, Ethics, and Control (Ensuring predictable AI behavior during failures)
*   **Chapter 15:** Mini-Project: Building a Simple Decision Game (Maze/grid navigation using rewards)
*   **Chapter 16:** Mini-Project: Testing Device Limits (Observing AI responses under constrained memory/lag)
