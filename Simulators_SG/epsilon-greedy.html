What to notice
  • With ε = 0 the AI never explores: if it happens to like Machine A first, it can stay there for ever (a local maximum).
  • With ε = 100% it explores every time, so it never uses what it learned.
  • One lucky or unlucky pull can mislead the average. More pulls make the estimates more reliable.
  • Change “1 pull in” to 20: Machine B is now the worse machine. Does exploring still help?
