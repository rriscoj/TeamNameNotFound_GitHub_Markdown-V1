## 6. Answers and Explanations

* **Question 1: B — CPU**
The CPU executes general program instructions and coordinates operations.
* **Question 2: C — Hold active data and instructions**
RAM is working memory providing fast access to active data.
* **Question 3: Model data must be accessible to processors**
Storage retains files long-term, but processors require data loaded into working memory (RAM/GPU memory) to execute calculations.
* **Question 4: Optimize workload or upgrade hardware**
Use a smaller/optimized model (reduces computation but may slightly lower accuracy) or increase GPU accelerator capacity (improves performance but costs more/uses more power).
* **Question 5: Correct order**
1. Capture the image
2. Make the required model data available in memory
3. Prepare the image for the model
4. Execute the model's calculations
5. Generate and display the prediction
