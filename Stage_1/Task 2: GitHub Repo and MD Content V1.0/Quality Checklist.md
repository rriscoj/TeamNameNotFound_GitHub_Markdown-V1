### Quality Checklist

Before submitting, check that:

- [x] The README identifies the team, module, project purpose, and locations of the materials.
  - **Comment: the readme includes team's detail, module information, project purpose and the material's location** 

- [x] The module outline covers the intended scope and follows a logical learning sequence.
  - **Comment: the module outline covers the planned topics in a clear step by step that is easy to follow** 

- [x] Development status is clearly labelled, with gaps and uncertainties acknowledged.
  - **Comment: the development status is laballed and any unfinished work or undertainties are mentioned** 

- [x] V1.0 contains substantive explanations and at least one coherent, well-developed topic—not only headings or plans.
  - **Comment: it contains detailed explanations and at least one topic that is fully developed, not just headings or plans** 

- [x] The developed material includes a worked example, an application activity or question, and an explained answer or expected outcome.
  - **Comment: the content includes a worked example, activity application and question as well and an explanation of the answer** 

- [x] Important claims and sources have been checked, and borrowed material is acknowledged.
  - **Comment: everything is have been checked and borrowed material is properly credited** 

- [x] Another member has reviewed the content, and a concrete review outcome is documented.
  - **Comment: one of the team member already reviewed the content and review and the changes made are recorded** 

- [x] Repository evidence shows actual development and supports each member’s claimed contribution.
  - **Comment: the repository shows the teams' actual work and provides evidence of each member's contributions** 

- [x] The package includes Markdown sources, supporting assets, a readable PDF, and the submission report; it can be assessed without opening external links.
  - **Comment: the package includes the Markdown files, supporting materials, a readable PDF, and the submission report, so the teacher can check everything without opening external links** 

- [x] Significant AI use is documented in the relevant logs, and members can explain the content and their own decisions.
  - **Comment: important uses of AI is recorded and all members can explain by their own understanding and their own decisions**
