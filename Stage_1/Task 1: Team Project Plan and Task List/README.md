3. Use meaningful commits that describe real changes; do not create artificial commits.
4. Have a different team member review substantive content where practical.
5. Record what was checked, what was found, and what was corrected or confirmed.
6. Record significant AI assistance and human verification honestly in the required project and personal logs. Keep personal logs private and outside the public repository.
7. Required submission material must be inside the submitted package; GitHub links are supplementary evidence, not a replacement for required files.
